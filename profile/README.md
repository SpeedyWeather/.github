# SpeedyWeatherOrg

The SpeedyWeather organization is part of [NumericalEarth](https://github.com/NumericalEarth)!

## Projects

- [SpeedyWeather.jl](https://github.com/SpeedyWeather/SpeedyWeather.jl), a global atmospheric model that is fast, extensible and interactive.
- [RingGrids.jl](https://speedyweather.github.io/SpeedyWeatherDocumentation/dev/ringgrids/) a library for iso-latitude grids on the sphere (and extended into N-dimensional arrays) and their interpolation for SpeedyWeather.jl.
- [LowerTriangularArrays.jl](https://speedyweather.github.io/SpeedyWeatherDocumentation/dev/lowertriangularmatrices/) a library for lower triangular matrices (and extended into N-dimensional arrays) used for the spherical harmonics in SpeedyWeather.jl.
- [SpeedyTransforms.jl](https://speedyweather.github.io/SpeedyWeatherDocumentation/dev/speedytransforms/) a library for the spherical harmonic transform between spectral space (using LowerTriangularArrays.jl) and grid-point space (using RingGrids.jl) used by SpeedyWeather.jl.

## Repositories for model setups

- (ARCHIVED) [StochasticStir.jl](https://github.com/SpeedyWeather/StochasticStir.jl), for stochastic stirring of vorticity in mid-latitudes with a jetstream-dependent drag term.
- [ManyZonalJets.jl](https://github.com/SpeedyWeather/ManyZonalJets.jl) as initial conditions for SpeedyWeather's shallow-water model with each jet following [Galewsky, 2004](https://doi.org/10.3402/tellusa.v56i5.14436).

## Repositories for SpeedyWeather analysis

- [RainMaker.jl](https://github.com/SpeedyWeather/RainMaker.jl), a repository to analyse and document the rainfall in one location.
- [TravellingSailorProblem.jl](https://github.com/SpeedyWeather/TravellingSailorProblem.jl), a repository to optimize trajectories of flying balloons.
- [SpeedyCalibration.jl](https://github.com/SpeedyWeather/SpeedyCalibration.jl), parameter calibration in SpeedyWeather.
- [Chiaroscuro.jl](https://github.com/SpeedyWeather/Chiaroscuro.jl), learn and optimize albedo.
